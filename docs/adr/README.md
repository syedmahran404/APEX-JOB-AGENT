# Architecture Decision Records (ADRs)

One file per decision. Numbered sequentially (`0001-*.md`, `0002-*.md`, ...). Format: short, linkable, immutable. Superseded ADRs are not deleted; a new ADR points back at the one it replaces.

The canonical short-form decision list lives in [`docs/architecture/00-overview.md`, §3](../architecture/00-overview.md#3-major-decisions-decision-log). Each row in that table will be expanded into a full ADR in M0.

Template: see `template.md` (added M0).
