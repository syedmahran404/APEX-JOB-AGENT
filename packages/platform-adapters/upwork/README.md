# `@apex/platform-adapters/upwork`

Upwork adapter. The semantic of "apply" here is **send a proposal**: a per-proposal cover letter (generated via the `cover.letter` prompt with an Upwork tone branch), an hourly or fixed-rate input, and milestone notes if applicable.
